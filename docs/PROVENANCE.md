# Source provenance and contributor notes

This consolidated repository was prepared from the project archives and source repositories supplied by the project owner.

## Source inputs reviewed

- Project owner's `bhargavsrikar-5/traveling` repository and local `traveling` folder — selected as the main application base because it contains the newer shipment-based web application plus the `Trip` / `TripStop` backend.
- Project owner's `bhargavsrikar-5/logistics` repository and local `Logistics_new` folder — supplied complementary landing-page and account-settings UI that was merged into the newer app.
- `hithesh1120/traveling` — reviewed as a closely matching collaborative source version; the core backend and several main frontend files are shared with the selected base.
- `hithesh1120/logistics-fullstack` — reviewed as a separate, older order-centric implementation. It was used as architectural reference only; its incompatible `/orders` model and legacy trip placeholder were not copied wholesale.
